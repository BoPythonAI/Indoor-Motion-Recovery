# Third-party dependencies and assets

This repository contains the project's control adapters, evaluation artifacts, and rendered demonstrations. Third-party frameworks, restricted body-model files, raw scene datasets, and pretrained tracker weights are not bundled.

| Component | Project | Role |
|---|---|---|
| ProtoMotions | https://github.com/NVlabs/ProtoMotions | Motion tracking and simulated-character framework |
| Isaac Lab | https://github.com/isaac-sim/IsaacLab | Physics simulation integration |
| HUMANISE | https://github.com/Silverster98/HUMANISE | Scene-aligned human reference motion |
| ScanNet | https://github.com/ScanNet/ScanNet | Indoor scene geometry and instance annotations |
| SMPL-X | https://smpl-x.is.tue.mpg.de/ | Human body assets used by mesh references |
| Qwen3-VL | https://github.com/QwenLM/Qwen3-VL | Instruction-to-relation parsing |

Each dependency and dataset retains its own license and access terms. Rendered demo media are outputs of the project and do not grant access to, or redistribute, the underlying licensed body-model or raw scene files.
